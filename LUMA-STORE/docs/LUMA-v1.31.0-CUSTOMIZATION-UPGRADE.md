# Luma Theme v1.31.0 customization upgrade

## What was completed

- Added a real WordPress Utility Menu location in the top utility bar; the original Track order and Help links remain as a fallback.
- Added a Footer Widgets sidebar so normal WordPress widgets can extend the footer without editing theme files.
- Added fallback Open Graph and Twitter metadata when a dedicated SEO plugin is not active. Existing SEO plugins remain the source of truth and are not duplicated.
- Added WooCommerce product review and review-form styling.
- Added print-friendly styles for order/content surfaces.
- Preserved Elementor, WooCommerce, RTL, reduced-motion, privacy and consent behavior.

No external dependencies, fabricated commerce signals, analytics changes or privacy weakening were introduced.
